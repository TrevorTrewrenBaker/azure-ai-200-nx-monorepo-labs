# Azure AI Cloud Developer Labs (Develop AI Cloud Solutions)

> **Status:** 🚀 Complete Study Path for **Develop AI Cloud Solutions on Azure** Certification.

## 🎯 Curriculum Coverage
This monorepo is structured to cover **all 8 Learning Paths** in the official Microsoft training course:

| Module | Lab Implementation | Tech Stack |
| :--- | :--- | :--- |
| **Container Hosting** | `apps/aks-lab`, `apps/container-apps-lab` | Docker, Kubernetes, Azure Container Apps |
| **AI with Cosmos DB** | `apps/cosmos-db-lab` | Cosmos DB (NoSQL), Vector Search |
| **AI with PostgreSQL** | `apps/postgres-lab` | Azure Database for PostgreSQL, Pgvector |
| **Azure Managed Redis** | `apps/redis-lab` | Azure Cache for Redis, Caching Strategies |
| **Backend Integration** | `libs/backend-integration` | Azure Functions, API Management |
| **Secrets Management** | `libs/secret-manager` | Azure Key Vault, Managed Identity |
| **Observability** | `apps/observability-lab` | Azure Monitor, Application Insights, Logs |
| **Troubleshooting** | `apps/troubleshooting-lab` | KQL Queries, Log Analytics |

## 🏗️ Architecture Highlights
- **Nx Monorepo**: Efficient workspace for microservices and shared libs.
- **AI-200 Exam Prep**: Covers all objectives for the **Azure AI Cloud Developer** role.
- **Data Persistence**: Demonstrates **Cosmos DB** and **PostgreSQL** for AI vector storage.
- **Caching & Performance**: Implements **Azure Redis** for high-speed AI inference caching.
- **Security**: Uses **Azure Key Vault** and **Workload Identity** for secret management.
- **Observability**: Full stack monitoring with **Azure Monitor**, **Grafana**, and **Application Insights**.

## 🚀 Key Skills Demonstrated
- **Infrastructure**: AKS, Container Apps, Docker, Helm.
- **Data**: Cosmos DB, PostgreSQL, Redis.
- **Security**: Key Vault, Managed Identity, RBAC.
- **Monitoring**: Log Analytics, KQL, Alerting.
- **Algorithms**: Custom logic integrated with AI services.
